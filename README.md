# Day 18 — Chop Chop London booking redesign concept

Unofficial frontend-only sales demo for the 100 Days Local Business Website Challenge.

This concept focuses on guided service discovery, transparent starting prices, guest-first exploration, a persistent booking basket, location guidance, appointment-change approval, final booking review, loyalty visibility, mobile responsiveness and reduced-motion support.

Demo availability is illustrative. This project is not connected to Fresha, does not create real appointments and does not process payments.

Files: index.html, css/style.css, js/main.js.
